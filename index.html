01 / About

I like building things that are useful, and getting the details right.

I'm studying Computational Media at Georgia Tech, where computer science and design sit side by side. That's exactly the overlap I want to work in: writing software and also caring about how it feels to use. I'm aiming for a career in software and product engineering, with design as part of how I think, not an afterthought.

I write code in Python and Java, build games in GameMaker, and design interfaces in Figma. My platformer, The Flower, is where a lot of that comes together: I wrote the movement and collision systems in GameMaker and made the art and UI to match.

I start by understanding the real problem before I build. For my ER triage project I read how emergency departments actually sort patients; for a Duolingo redesign I wrote a user persona first. I'd rather ship something that fits how people work than something that just looks impressive.

I also build with AI tools like Kiro and Claude. The HTML, CSS, and JavaScript behind several of my projects, including this site, were generated with that help. I use AI to turn an idea into a working prototype quickly, to explore options, and to learn the web stack as I go, while I own the direction and the decisions. Being able to use these tools well is a skill I'm deliberately building.
