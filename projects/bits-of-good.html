Bits of Good Bootcamp

Figma design work · Georgia Tech · Sept 2026 – Present

FigmaUI/UXPrototypingAuto Layout

A design bootcamp at Georgia Tech where I practice interface design in Figma each week. The carousel below is where I apply it: redesigning real product screens and studying how strong interfaces are put together.

Situation

I joined Bits of Good's Figma bootcamp at Georgia Tech to build hands-on interface and visual design skills.

Task

Work through weekly Figma exercises covering layouts, components, and visual hierarchy, and apply them to real product screens.

Action

I recreated an Apple-style interface, redesigned Duolingo's profile pages from a user persona, rebuilt an Etsy checkout with Auto Layout and adapted it for mobile, prototyped a Pinterest onboarding flow, and redesigned the Letterboxd search page.

Outcome

A gallery of interface redesigns that show cleaner layouts and clearer hierarchy, and a stronger grasp of how to structure a design in Figma.

  • 🍎 Recreated an Apple-style interface to study layout and hierarchy
  • 🦉 Redesigned Duolingo profile pages from a user persona (before and after)
  • 🛒 Rebuilt an Etsy checkout with Auto Layout and adapted it for mobile
  • 📌 Prototyped a Pinterest onboarding and category-selection flow
  • 🎬 Redesigned the Letterboxd search page with filters
